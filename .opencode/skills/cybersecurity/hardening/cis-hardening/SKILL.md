# CIS Hardening

Use this skill to define hardening, secure configuration, baselines, technical hygiene, and control prioritization using CIS Controls and CIS Benchmarks.

## Framework Base

- CIS Controls for prioritizing essential hygiene, visibility, protection, and response.
- Implementation Groups IG1, IG2, and IG3 for scaling effort by maturity and risk.
- CIS Benchmarks for secure configuration of operating systems, cloud, containers, databases, and applications when applicable.

## Workflow

1. Identify the platform, scope, criticality, data, exposure, and operational constraints.
2. Assess inventory, configuration, identities, privileges, vulnerabilities, logs, backups, and malware defenses.
3. Propose a minimum baseline and a target baseline by maturity.
4. Prioritize controls by impact, effort, dependency, operational risk, and automation potential.
5. Define evidence, compliance checks, exceptions, and review cadence.

## Expected Output

Provide control, objective, recommended configuration, priority, operational impact, expected evidence, validation, and acceptable exceptions.

## Limits

Do not apply destructive changes without confirmation. Distinguish between recommendation, verification, and actual hardening execution.
