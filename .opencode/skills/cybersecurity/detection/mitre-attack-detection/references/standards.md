# MITRE ATT&CK Detection References

Target version: v19.1.

## Official Sources

- MITRE ATT&CK: https://attack.mitre.org
- Detection strategies: https://attack.mitre.org/detectionstrategies/
- Analytics: https://attack.mitre.org/analytics/
- Data components: https://attack.mitre.org/datacomponents/

## Scope Notes

Use this skill for detection engineering, threat hunting, telemetry mapping, SIEM/EDR/NDR coverage, and false-positive analysis.

## Validation Guidance

Validate that detections are tied to observable behavior and required data sources. Avoid mapping detections only by tool or malware family name.
