## Scope Notes

Use this skill for GenAI application risk, LLM workflows, RAG, agentic AI, tools/plugins, prompts, output handling, and application controls. Use `mitre-atlas-2026` for adversarial AI TTPs and `nist-ai-rmf-10` for AI risk governance.

## ID Conventions

- OWASP GenAI LLM Top 10 items should be cited with their current published category IDs and names.
- Historical categories such as `LLM01` through `LLM10` should be marked as historical if using pre-2026 sources.
- Cross-framework references should identify ATLAS AML IDs or NIST AI RMF function names when used.

## Validation Guidance

Validate category names and IDs against the current OWASP GenAI source before formal reporting. Do not reuse archived LLM Top 10 category names as current without checking the 2026 release.
