# OWASP References

Target versions: Top 10 2021, API Security Top 10 2023, ASVS 4.0.3, SAMM 2.0.

## Official Sources

- OWASP: https://owasp.org
- OWASP Top 10: https://owasp.org/www-project-top-ten/
- OWASP API Security: https://owasp.org/www-project-api-security/
- OWASP ASVS: https://owasp.org/www-project-application-security-verification-standard/
- OWASP SAMM: https://owasp.org/www-project-samm/

## Scope Notes

Use OWASP for application and API security reviews, including authentication, authorization, input handling, dependency risk, secrets, logging, and secure design.

## Validation Guidance

Map findings to the most specific applicable OWASP project. Do not overstate ASVS level compliance without evidence.
