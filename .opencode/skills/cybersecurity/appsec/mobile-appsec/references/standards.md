# Mobile Application Security References

Target versions: current OWASP MASVS, MASWE, and MASTG.

Last verified: 2026-09-08.

Pinning rationale: OWASP Mobile Application Security documentation is the active source for MASVS controls, MASWE weaknesses, and MASTG tests. Use the current site for exact identifiers when reporting.

## Official Sources

- OWASP MASVS: https://mas.owasp.org/MASVS/
- OWASP MASWE: https://mas.owasp.org/MASWE/
- OWASP MASTG: https://mas.owasp.org/MASTG/
- OWASP MASTG GitHub: https://github.com/OWASP/owasp-mastg

## Scope Notes

Use this skill for Android, iOS, hybrid, and cross-platform mobile application assessment. Use `owasp-appsec` for general web/API issues and `vulnerability-risk-prioritization` for specific CVE triage.

## ID Conventions

- MASVS controls use identifiers such as `MASVS-STORAGE-1`.
- MASWE weaknesses use identifiers such as `MASWE-0001`.
- MASTG tests use identifiers such as `MASTG-TEST-0001`.
- MASTG knowledge and best-practice entries use their official `MASTG-KNOW-*` and `MASTG-BEST-*` identifiers.

## Validation Guidance

Validate exact mobile control, weakness, and test IDs against current OWASP MAS documentation before formal reporting. Distinguish platform-specific Android and iOS evidence.
