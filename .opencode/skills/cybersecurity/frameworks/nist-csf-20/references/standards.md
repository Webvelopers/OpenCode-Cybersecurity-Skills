# NIST CSF References

Target version: 2.0.

## Official Sources

- NIST CSF resource center: https://www.nist.gov/cyberframework
- NIST CSF 2.0 publication: https://doi.org/10.6028/NIST.CSWP.29
- CSF 2.0 reference tool: https://csrc.nist.gov/Projects/cybersecurity-framework/Filters#/csf/filters
- Informative references: https://www.nist.gov/cyberframework/informative-references

## Scope Notes

CSF 2.0 is outcome-based and flexible. It should be used to create current and target profiles, communicate risk, and prioritize improvement work.

## ID Conventions

- Functions use `GV`, `ID`, `PR`, `DE`, `RS`, and `RC`.
- Categories use IDs such as `GV.OC`, `ID.AM`, or `DE.CM`.
- Subcategories use IDs such as `GV.OC-01`.

## Validation Guidance

Do not present CSF as a certification. Validate subcategory IDs through NIST tools when producing formal reports.
